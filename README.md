# Last Ledger

A roguelike fantasy accounting game. You never fight; you approve budgets, loans, contracts, and bribes. The fate of the kingdom depends on your ledger.

## Tech
- React + TypeScript + Vite
- Zustand store
- Deterministic seeded RNG (runs are shareable)
- Data-driven content (policies, rulers, events, requests)
- LocalStorage meta progression

## Run locally
```bash
npm install
npm run dev
